# Spawn_RB — Отслеживатель респавна рейд-боссов (Lineage 2 LU4)

Локальный веб-сервер на Python (FastAPI) с облачной синхронизацией (PostgreSQL / Neon) и автоматическими уведомлениями в Telegram для пати и кланов.

## Возможности
- **Актуальная база LU4:** 155 рейд-боссов с их точными уровнями и динамическими окнами респавна.
- **Синхронизация между драйверами:** все таймеры хранятся в облачной БД — сервер можно безболезненно перезапускать на разных ПК без потери времени и без дублей в Telegram.
- **Умная сортировка и поиск:** боссы с открытым окном («РЕСП ПОШЕЛ»), заспавнившиеся («СТОИТ») и убитые автоматически поднимаются наверх таблицы.
- **Удобный ввод:** фиксация убийства в один клик с защитой от даблклика или ручной ввод времени (`ЧЧ:ММ`).
- **Telegram-уведомления:** автоматическая отправка сообщений в групповой чат при открытии окна респавна и при 100% спавне.

## Быстрый старт (из исходников)
1. Скопируйте `config.example.py` в `config.py` и укажите строку подключения к PostgreSQL, токен бота и ID чата.
2. Запустите `start.bat` (скрипт сам установит зависимости из `requirements.txt` и откроет интерфейс в браузере по адресу `http://localhost:8000`).
